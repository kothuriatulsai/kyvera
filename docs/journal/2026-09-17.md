## What was attempted

Scaffolded the repo structure for Module 1, step 1 of the build order:

- Monorepo layout: `apps/api`, `apps/web`, `packages/shared-types`,
  `docs/architecture`, `docs/journal`.
- `apps/api` — Express + TypeScript skeleton with the
  `routes/controllers/services/repositories` layering (empty, with a
  placeholder `prisma/` dir for the schema that comes in step 2). Added a
  minimal `/health` endpoint and one Supertest test, mostly to prove the
  lint/typecheck/test pipeline actually runs end to end rather than to
  demonstrate anything about the domain.
- `apps/web` — React + TypeScript + Vite via `npm create vite@latest`,
  stripped down from the default template (removed the demo counter, hero
  image, and icon sprite) to a blank placeholder page, wired up Vitest +
  Testing Library for a smoke test.
- `docker-compose.yml` with Postgres 16, plus Dockerfiles for `api` and
  `web` (dev-mode, volume-mounted source).
- `.github/workflows/ci.yml` running `npm run lint`, `npm run typecheck`,
  `npm run test` across the npm workspaces on every PR and push to `main`.
- Root `README.md` (problem statement, module roadmap, architecture,
  local setup) and the first two ADRs (`0001-postgres-over-mongodb`,
  `0002-monorepo-structure`).

## What broke / notable decisions

- The architecture doc places `prisma/` under `apps/api/src/`, which isn't
  where Prisma's CLI expects it by default (it looks for
  `apps/api/prisma/`). Followed the doc as written for step 1 since Prisma
  itself isn't being initialized yet — this will need a decision (or a
  `schema.prisma` `--schema` path override) when step 2 actually runs
  `prisma init`.
- Skipped adding actual Prisma dependencies/config in `apps/api` — step 1
  is scaffolding only, no business logic or ORM setup yet. `apps/api/src/prisma/`
  exists as an empty placeholder.
- Kept `routes/`, `controllers/`, `services/`, `repositories/` empty
  (`.gitkeep` only) per the brief; the only real code in `apps/api` right
  now is `app.ts`/`index.ts` bootstrapping Express and the `/health` check.
